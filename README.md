# Deloitte Australia - Forensic Technology & Data Analytics Virtual Experience

This repository contains the tasks completed during the Deloitte Australia Virtual Experience Program on Forage. The project focuses on data analysis using Tableau and forensic technology data classification.

## 📋 Project Tasks Overview

* **Task 1: Data Analysis (Telemetry & Automation)**
  * Analyzed factory telemetry data collected by Daikibo using Tableau.
  * Created calculated measures ("Unhealthy" status) to identify machine downtime.
  * Developed an interactive dashboard with bar charts tracking "Down Time per Factory" and "Down Time per Device Type".

* **Task 2: Forensic Technology (Equality Class Automation)**
  * Processed employee compensation data to audit pay equity.
  * Created an automated logic column (`Equality class`) to classify data into:
    * **Fair** (Score: -10 to +10)
    * **Unfair** (Score: <-10 and >10)
    * **Highly Discriminative** (Score: <-20 and >20)
